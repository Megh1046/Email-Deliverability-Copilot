# Definition of Done (DoD)

A task is considered complete only if **all** of the following conditions are met.

## Functionality

- The requested feature is implemented.
- The feature works as described.
- No out-of-scope functionality has been added.

---

## Code Quality

- Code is readable.
- Type hints are present.
- Functions remain focused and small.
- No duplicated code.
- No unnecessary abstractions.

---

## Architecture

- Existing folder structure is respected.
- Existing architecture is respected.
- No architectural decisions were changed without approval.

---

## Verification

- The feature has been manually verified.
- Expected outputs are documented.
- Startup succeeds.
- No runtime errors.

---

## Context

The following files have been updated:

- CURRENT_STATE.md
- NEXT_TASK.md
- CHANGELOG.md

DECISIONS.md only if required.

---

## Git

A Conventional Commit message has been suggested.

---

## Completion

If any checklist item is incomplete,

the task is NOT done.
